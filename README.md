# Nancy's System — Nancy Work System

Precious, strong bar/club stock-control system. One app (`nancy.html`) with:

- 🥤 Drinks stock sheet (9 columns, prices, autofill, auto-save drafts)
- 🧾 Daily sales recording · 💸 Expense tracking · 💰 Cash reconciliation + shift handover
- 📒 Debts ledger · 📦 Restock orders with suppliers · 🧾 Breakage & wastage log
- 📝 Reports with charts + weekly/monthly PDF export (generated from scanned data)
- 🤖 AI predictor (closing forecasts, mistake detection, solutions) + scanned-document checks
- 📤 Upload & Scan (OCR, phone-text import, mistake underline → authorize rectify → assurance)
- 📑 Scanned Data vault (AI check-all, rectify-all, user-controlled delete)
- 🧮 Stock formulas · ⚙️ Settings (staff, email, strong passwords, backup/restore)
- 📲 Installable PWA + desktop launcher + living underwater scene

## Run

Double-click `start-app.bat`, or:

```
node "C:\Users\NANCY\Downloads\nancy work system\server.js"
```

then open http://localhost:8080/nancy.html (login at http://localhost:8080).

## Data

All data lives in the browser (localStorage). Back up anytime from Settings → Backup & Restore.
